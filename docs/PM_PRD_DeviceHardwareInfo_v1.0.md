# 产品需求说明书 (PRD) - Android 设备硬件信息模块 v1.0

## 1. 需求背景
目前 Little-Tyrant 工具主要侧重于 Android 的 APK 安装、文件管理以及 Windows VPN 控制。但在测试和开发过程中，尤其是针对 Unity/Unreal 等游戏开发，了解目标设备的**显卡 (GPU) 型号**和**芯片平台 (SoC)** 等底层硬件信息是非常关键的。
为了减少用户手动在终端中敲击冗长 ADB 命令的麻烦，我们需要在现有的 Android 工具模块中新增“设备硬件信息查询”功能，直观地展示这些核心参数。

## 2. 核心功能描述

### 2.1 硬件信息提取能力
工具需要能够自动获取当前所连接设备的以下关键信息：
- **GPU 型号**（例如 `Mali-G78`, `Adreno (TM) 740` 等）。
- **OpenGL ES 版本**（例如 `OpenGL ES 3.2`）。
- **芯片平台 (SoC Board Platform)**（例如 `gs101`, `taro` 等）。
- **设备制造商与机型**（例如 `Google Pixel 6`，用于辅助确认设备）。

### 2.2 UI 呈现与交互
在目前的 `Android 工具` Tab 内，新增一个可视化的“设备信息展示区”（或者在已有的设备选择器旁新增一个“硬件信息”面板 / 悬浮气泡 / 专用子页面）。
- **触发机制**：当下拉框选中某个设备时，自动/异步查询该设备的硬件信息并显示。
- **展示风格**：遵循已经制定的 “极简大色块科技风 (Tech Theme)” 标准。例如使用暗色卡片背景、高亮彩色字体（如 `#00ffcc` 科技绿或 `#7aa2f7` 霓虹蓝）来突出 GPU 等关键参数。
- **异常处理**：若某些设备因权限或非标准系统导致查询不到 GPU，需显示友好的提示语“未知设备/获取失败”，不能导致主程序崩溃。

## 3. 验收标准
1. **兼容性**：能在 Pixel (Google Tensor/Mali)、常规骁龙机型上正常读取并提取 GPU 关键文本。
2. **零卡顿**：信息的抓取需要通过异步方式或在设备切换时快速完成，不阻塞主界面的流畅度。
3. **视觉一致性**：新加入的面板 UI 不得破坏当前极简无边框的设计原则。
