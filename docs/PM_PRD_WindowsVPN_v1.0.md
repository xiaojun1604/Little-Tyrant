# 产品需求说明书 (PRD) - Windows VPN 管理器 v1.0

## 1. 项目背景
在日常开发与测试中，开发者经常需要高频切换内网与外网环境（例如连入公司的内网 VPN `v.corp.sdo.com`）。Windows 系统自带的 VPN 管理界面层级较深，操作繁琐，且状态感知不够直观。
为提升效率，我们计划在 **Little-Tyrant** 极客工具箱中增加一个“VPN 管理器”模块，允许用户在工具内直接控制 Windows 系统 VPN 的开关，并能快速唤出系统的详细设置页面。

## 2. 核心需求描述

### 2.1 自动读取与展示 VPN 列表
- **需求描述**：工具打开或切换到 VPN 管理标签时，自动读取当前 Windows 电脑上已配置的所有 VPN 连接（基于系统电话簿配置）。
- **展示方式**：采用列表视图展示 VPN 名称，并在名称旁通过清晰的视觉标识（如绿点、文字标签）指示当前是否处于“已连接”状态。

### 2.2 连接与断开控制
- **需求描述**：
  - 若 VPN 未连接，提供“连接”按钮，点击后触发系统拨号（使用系统中已保存的账号密码）。
  - 若 VPN 已连接，提供“断开”按钮，点击后切断连接。
- **状态同步**：因为用户可能在 Windows 任务栏或设置中操作 VPN，工具内的状态需要具有一定的实时感知能力（可定时刷新）。

### 2.3 快速打开系统 VPN 设置
- **需求描述**：在界面显眼处提供一个“打开系统 VPN 设置”按钮。
- **行为预期**：点击后直接跳转至 Windows 自带的 `设置 -> 网络和 Internet -> VPN` 面板，方便用户新增、编辑或配置账户。

### 2.4 全局一键开关
- **需求描述**：在顶部工具栏增加“默认 VPN”选择下拉框及“全局一键连接/断开”按钮。
  - 打开时，自动连接选中的“默认 VPN”；关闭时，断开当前正在连接的 VPN。
- **状态联动**：全局开关的状态应当与底层真实连接状态实时联动。

### 2.5 路由与全局模式切换 (Split Tunneling)
- **需求描述**：允许用户一键切换单条 VPN 的“全局模式”（即底层 Windows 的 Split Tunneling 选项）。
  - **开启全局模式**：所有本地流量无条件路由到 VPN。（对应 Split Tunneling = False）
  - **关闭全局模式（路由模式）**：仅内网网段流量走 VPN，不影响正常上网。（对应 Split Tunneling = True）
- **交互逻辑**：
  - 在列表的每条 VPN 记录旁增加一个 `[ ] 全局模式` 的复选框（QCheckBox）。
  - **限制与重连机制**：由于 Windows 机制限制，如果用户在 VPN **已连接**的状态下切换该开关，则弹窗提示“更改模式需要重新连接，是否立即重连？”。用户点“是”后，后台自动执行：断开 -> 更改配置 -> 重新连接。未连接状态下则直接静默修改。

## 3. 界面交互与视觉设计
- **风格继承**：全面继承已经调优的极简大色块“科技风 (Tech Theme)”设计。
- **布局设计**：
  - **顶部操作栏**：包含“默认 VPN 选择下拉框”、“全局开关按钮”、“刷新列表”和“⚙️ 系统 VPN 设置”按钮。
  - **主体区域**：流式列表（List/Card 视图）。每条记录左侧为 VPN 名称与状态灯，中部为“全局模式”复选框，右侧为“操作按钮”（Hover态变化，已连接时按钮可能变红警示为“断开”）。
- **交互反馈**：连接或断开时若有耗时（拨号等待），需提供 UI 屏蔽或等待反馈（如禁用按钮并显示“连接中...”）；操作成功或失败后通过 `QMessageBox` 或气泡给出提示。
